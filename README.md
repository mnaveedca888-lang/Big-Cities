# Global AI Event Monitoring Platform

A premium React 19 + TypeScript frontend for an enterprise-grade global event monitoring experience.

## Current status
The frontend is implemented, responsive, tested, lint-clean, and build-ready. The project is now documented for backend handoff and AI-assisted continuation.

## Features
- Responsive public experience with premium layout and navigation
- Event discovery, category browsing, country and city views
- Dashboard and admin surfaces
- Authentication UI and error states
- API-ready service layer and typed models
- Theme support and accessible UI primitives
