# Asia Country Banner Image Audit

Generated from the live database country/continent relation, API, static image server, and filesystem on 2026-09-30. The authoritative scope is `Country.continent.name = Asia`; the country slug below is normalized from the database name because the Country model has no slug field.

## Totals

- Total Asian countries: 49
- Existing valid country images retained: 2
- Newly downloaded country images: 47
- Total valid country images: 49
- Unresolved countries: 0
- Invalid/wrong-country active API images: 0
- Non-WebP images: 2 (pre-existing Afghanistan and Pakistan JPEGs; all new files are WebP)
- Duplicate/wrong assignments: 0

The 47 new WebPs use the existing `backend/public/Images/Asia cities images` directory and database-country normalization flow. The API returned 49/49 country detail responses with HTTP 200; all 47 new image URLs returned HTTP 200 with `Content-Type: image/webp`; Afghanistan and Pakistan returned HTTP 200 with `Content-Type: image/jpeg`. For each row, the React page's profile-first hero value matches the API image. The UAE country page was exercised in the browser; its resolved WebP hero loaded with non-zero natural dimensions.

Every new image is a Wikimedia Commons photograph. The linked article or Commons file description/category was checked for an exact-country location. The North Korea source is a Mount Paektu photograph whose Commons categories explicitly identify North Korea. Bangladesh uses an Inani Beach image explicitly located in Cox's Bazar, Bangladesh, replacing the cross-border Sundarbans candidate.

The original country profile JSON was not modified. Azerbaijan's former Unsplash URL and India's former India Gate URL were broken, but API normalization now returns their exact local WebPs instead; these stale profile values are not active API assignments and are not counted as invalid images.
