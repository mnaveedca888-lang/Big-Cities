# Backend Module List

Domain modules and responsibilities:

- auth: authentication flows, refresh tokens, password reset, verification
- users: profile read/update, preferences, avatar management
- roles_permissions: role and permission management, RBAC utilities
- events: event CRUD, featured, event detail
- catalog: categories, countries, cities
- search: search endpoints, suggestions, indexing
- dashboard: overview counts, recent activity, saved events/watchlist
- analytics: metrics and aggregated summaries
- notifications: CRUD, mark-as-read, delivery
- uploads: signed URLs and file metadata
- admin: admin-only operations and moderation
- jobs: background job processors and scheduled tasks
- common: shared middleware, guards, error handling, DTOs
- infra: monitoring, logging, and deployment manifests
